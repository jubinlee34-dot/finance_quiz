# 🏦 경제꿈터 금융 방탈출 퀴즈

초등학생을 위한 금융 교육용 방탈출 웹 퀴즈 게임입니다.  
4개의 방을 순서대로 클리어하고 최종 방탈출에 도전하세요!

🔗 **플레이 링크:** [https://jubinlee34-dot.github.io/finance_quiz/](https://jubinlee34-dot.github.io/finance_quiz/ )

---

## 🎮 게임 구성

| 방 | 유형 | 문제 수 | 클리어 조건 |
|:---:|---|:---:|---|
| 1번방 | 4지선다 퀴즈 | 10문제 | 전 문제 정답 |
| 2번방 | O / X 퀴즈 | 10문제 | 전 문제 정답 |
| 3번방 | 초성 퀴즈 | 10문제 | 전 문제 정답 |
| 4번방 | 카드 매칭 | 8쌍 | 8쌍 전부 매칭 |

4개 방을 모두 클리어하면 **방탈출 도전 버튼**이 활성화됩니다.

---

## ✨ 주요 기능

- **오답 3회 제한** — 같은 방에서 오답이 3회 누적되면 해당 방 처음부터 재시작
- **힌트 시스템** — 전체 3회 사용 가능 (방별 힌트 텍스트 제공)
- **설명 토스트** — 정답 후 해설이 화면 하단에 잠깐 표시되고 자동 삭제
- **진행 상태 저장** — `localStorage`로 새로고침 후에도 진행 상황 유지
- **셔플** — 매 게임마다 문제 순서와 카드 위치가 랜덤으로 섞임
- **성공 애니메이션** — Confetti + 별 파티클 효과
- **전체화면 지원** — 우상단 버튼으로 전체화면 전환
- **반응형 레이아웃** — 모바일 / 태블릿 / 데스크탑 모두 지원

## 📝 퀴즈 데이터 수정 방법

퀴즈 내용은 `data/quizData.json` 파일에서 수정합니다.

### 1번방 — 4지선다 (`room1`)

```json
{
  "id": 1,
  "question": "문제 텍스트",
  "options": ["보기1", "보기2", "보기3", "보기4"],
  "answer": "보기1",
  "explanation": "정답 해설 (선택)"
}
```

> `answer` 값은 반드시 `options` 배열의 텍스트와 **정확히 동일**해야 합니다.

### 2번방 — O/X 퀴즈 (`room2`)

```json
{
  "id": 11,
  "question": "문제 텍스트",
  "options": ["O", "X"],
  "answer": "O",
  "explanation": "정답 해설 (선택)"
}
```

### 3번방 — 초성 퀴즈 (`room3`)

```json
{
  "id": 21,
  "question": "문제 텍스트 (ㅈㄱㅈㄱ)",
  "answer": "정기적금",
  "explanation": "정답 해설 (선택)"
}
```

### 4번방 — 카드 매칭 (`room4`)

```json
{
  "id": 31,
  "question": "카드에 표시될 문제 텍스트",
  "answer": "M1"
}
```

> `answer`는 매칭할 이미지 파일명(확장자 제외)입니다.  
> 이미지는 `images/matching/` 폴더에 저장하세요.

## 🖼️ 이미지 교체 방법

| 파일 | 용도 | 권장 크기 |
|---|---|---|
| `images/1.png` ~ `images/4.png` | 방 선택 화면 썸네일 | 정사각형 |
| `images/L1.png` ~ `images/L3.png` | 최종 방탈출 화면 이미지 | 자유 |
| `images/matching/M1.png` ~ `M8.png` | 4번방 카드 매칭 이미지 | **1:1 정사각형 권장** |

## 🚀 로컬 실행 방법

별도 서버 없이 `index.html`을 브라우저에서 직접 열면 됩니다.  
단, `quizData.json`을 불러오기 위해 로컬 서버가 필요한 경우:

```bash
# Python 3
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```
