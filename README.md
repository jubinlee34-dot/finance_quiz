# 🏦 경제꿈터 금융 방탈출 퀴즈

초등학생을 위한 금융 교육용 **방탈출 웹 퀴즈 게임**입니다.
4개의 방을 순서대로 클리어하고 최종 방탈출에 도전하세요!

🔗 **플레이 링크:** [https://jubinlee34-dot.github.io/finance_quiz/](https://jubinlee34-dot.github.io/finance_quiz/)

---

## 🎯 게임 목표

4개의 방에서 금융 퀴즈를 풀고 각 방의 **암호 숫자**를 획득한 뒤,
최종 암호 패드에 4자리 코드를 입력하여 방탈출을 완성합니다.

---

## 🎮 방탈출 게임 방법

### 1단계 — 난이도 선택

| 난이도 | 대상 | 문제 수 |
|:---:|---|:---:|
| 🌱 **저학년** | 1~3학년 (기초 금융 상식) | 총 19문제 |
| 👑 **고학년** | 4~6학년 (심화 금융 지식) | 총 38문제 |

### 2단계 — 게임 설명서 확인

난이도 선택 후 게임 방법 안내 화면이 표시됩니다.
내용을 확인한 뒤 **방탈출 시작!** 버튼을 누르세요.

### 3단계 — 4개 방 클리어

각 방을 순서대로 클리어하며 암호 숫자를 획득합니다.

| 방 | 유형 | 문제 수 (저학년 / 고학년) | 획득 암호 |
|:---:|---|:---:|:---:|
| 🚪 **1번방** | 4지선다 퀴즈 | 5 / 10문제 | **6** |
| 🚪 **2번방** | O / X 퀴즈 | 5 / 10문제 | **3** |
| 🚪 **3번방** | 초성 퀴즈 | 5 / 10문제 | **15** |
| 🚪 **4번방** | 카드 매칭 | 4 / 8쌍 | **2** |

#### 방별 규칙

**1번방 — 4지선다**
4개의 보기 중 정답을 선택합니다. 문제와 보기 순서는 매번 랜덤으로 섞입니다.

**2번방 — O / X 퀴즈**
문장이 맞으면 O, 틀리면 X를 선택합니다.

**3번방 — 초성 퀴즈**
제시된 초성을 보고 금융 단어를 맞힙니다.
마지막 문제는 이미지를 보고 정답을 계산합니다.

**4번방 — 카드 매칭**
카드가 랜덤으로 배치됩니다 (저학년 8장 / 고학년 16장).
**?** 카드를 클릭하면 문제가 팝업으로 표시되고, 해당하는 이미지 카드를 선택해 매칭합니다.
매칭 성공 시 ? 카드가 밝은 색으로 바뀌며 문제 텍스트가 표시됩니다.

#### 공통 규칙

| 규칙 | 내용 |
|---|---|
| **오답 제한** | 같은 방에서 오답 3회 누적 시 해당 방 처음부터 재시작 |
| **오답 카운트** | 정답을 맞혀도 카운트는 초기화되지 않음 (방 재시작 시에만 초기화) |
| **힌트** | 전체 3회 사용 가능 — 현재 문제의 해설을 팝업으로 표시 (4번방 제외) |
| **설명 토스트** | 정답 후 해설이 화면 하단에 잠깐 표시되고 자동 삭제 |
| **진행 저장** | 새로고침 후에도 진행 상황이 자동 저장·복원됨 |
| **셔플** | 매 게임마다 문제 순서와 카드 위치가 랜덤으로 섞임 |

### 4단계 — 최종 방탈출 암호 입력

4개 방을 모두 클리어하면 **방탈출 도전** 버튼이 활성화됩니다.
암호 패드에서 각 방에서 획득한 숫자를 순서대로 입력하세요.

> **최종 암호: 6 → 3 → 15 → 2**

정답을 입력하면 방탈출 성공 화면이 표시됩니다! 🎉

## 🕹️ 미니게임: 금융 단어 팡팡!

방탈출 성공 화면에서 **🎮 미니게임 하기** 버튼을 누르면 진입합니다.

### 게임 방법

**금융 단어 팡팡**은 8×8 글자 보드에서 숨겨진 금융 단어를 찾는 **워드서치(Word Search)** 게임입니다.

| 항목 | 내용 |
|---|---|
| **제한 시간** | 5분 (300초) |
| **단어 수** | 12개 (매 게임 랜덤 선택) |
| **조작 방법** | 단어의 첫 글자부터 마지막 글자까지 **드래그** (터치 지원) |
| **방향** | 가로, 세로, 대각선 (8방향) 모두 가능 |

### 점수 체계

| 구분 | 점수 |
|---|---|
| 쉬운 단어 (2글자) | 기본 1점 |
| 보통 단어 (2~3글자) | 기본 2점 |
| 어려운 단어 (3~6글자) | 기본 3점 |
| ⭐ **황금 단어** | 기본 점수 × **3배** + 시간 +10초 |
| 🔥 **콤보** | 2.2초 안에 연속 발견 시 콤보 배수 적용 |
| 🏆 **전체 클리어** | 12단어 모두 찾으면 새 보드 생성 + 시간 +20초 |

### 주요 기능

- **황금 단어**: 매 게임 랜덤 1개 지정 — 단어 목록에서 ⭐ 표시로 확인
- **콤보 시스템**: 빠르게 연속으로 단어를 찾으면 COMBO 배수 증가
- **파티클 효과**: 단어 발견 시 화려한 파티클 애니메이션
- **효과음**: 발견·콤보·황금 단어별 효과음 (🔊 버튼으로 음소거)
- **점수 저장**: 최고 기록 및 지난 기록 자동 저장
- **🏠 돌아가기**: 방탈출 성공 화면으로 복귀

### 포함 금융 단어 (30개 풀에서 랜덤 12개)

| 난이도 | 단어 목록 |
|---|---|
| 쉬움 (1점) | 저축, 수입, 지출, 수표, 용돈, 이자, 세금, 주식, 환율, 보험 |
| 보통 (2점) | 신용, 예금, 적금, 원리금, 수익, 소비, 생산, 부채, 대출, 자산, 재산, 통장 |
| 어려움 (3점) | 가계부, 정기적금, 금융사기, 신용카드, 소득공제, 예금적금, 지출관리 |

## 🛠️ 수정 가이드

### 퀴즈 내용 변경
`data/quizData.json` 파일을 수정합니다.

```json
// 1번방 (4지선다) 예시
{ "id": 1, "question": "문제 텍스트", "options": ["보기1","보기2","보기3","보기4"], "answer": "보기1", "explanation": "해설" }

// 2번방 (OX) 예시
{ "id": 11, "question": "문장", "answer": "O", "explanation": "해설" }

// 3번방 (초성) 예시
{ "id": 21, "question": "ㅈㄱㅈㄱ", "answer": "정기적금", "explanation": "해설" }

// 4번방 (카드매칭) 예시
{ "id": 31, "question": "카드에 표시될 문제 텍스트", "answer": "M1" }
```

> **주의:** `answer`는 `options` 배열의 텍스트와 **정확히 동일한 문자열**이어야 합니다.

### 방 코드 / 힌트 변경
`index.html`의 `ROOM_CONFIG` 상수를 수정합니다.

### 최종 암호 변경
`CORRECT_CODES` 배열과 각 방의 `code` 값을 **함께** 수정합니다.

### 키패드 글자 변경
`KEYPAD_BUTTONS` 배열을 수정합니다.
